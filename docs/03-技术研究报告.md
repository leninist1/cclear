# CClear 技术研究报告

## 1. 技术目标

在 Windows 环境下快速交付一个真正可运行的桌面端原型，覆盖扫描、搜索、清理三类核心能力，并保证后续能够继续迭代为更完整的产品。

## 2. 候选技术路线

## 2.1 Electron

### 优点

- 界面表现力强
- 前端生态成熟
- 适合复杂交互式工作台

### 缺点

- 需要额外运行时二进制
- 包体和资源占用偏大
- 当前环境下 Electron 运行时安装验证不稳定，不利于快速形成可交付原型

## 2.2 Tauri

### 优点

- 包体更小
- 性能和资源占用更好
- 适合后续做长期产品化

### 缺点

- 依赖 Rust 工具链
- 当前环境未安装 Rust，原型启动成本偏高

## 2.3 Python + Tkinter

### 优点

- 当前环境已具备 Python
- Tkinter 属于标准库，无需额外依赖
- 可以直接做本地文件系统访问、线程任务和 Windows API 调用
- 最适合在空仓库中快速交付可运行桌面原型

### 缺点

- UI 视觉表现不如现代前端框架灵活
- 大规模复杂交互下，后续可能需要升级界面技术

## 2.4 C# / WPF

### 优点

- Windows 原生体验更强
- 与系统集成能力优秀

### 缺点

- 当前环境与仓库没有现成基础
- 快速原型成本高于 Python 方案

## 3. 技术决策

当前阶段选择：

- 桌面框架：Python + Tkinter
- 本地能力：Python 标准库
- Windows 回收站能力：`ctypes` 调用 Shell API
- 测试方式：`unittest`

## 4. 选择 Python + Tkinter 的原因

- 用户需要的是桌面工具，而不是 Web 应用
- 当前环境已有 Python，可直接开发并验证
- Tkinter 无需额外安装，能显著降低环境不确定性
- 文件系统扫描、搜索、清理本质上是本地 IO 与系统调用任务，Python 标准库完全可以覆盖原型阶段需求
- 先交付能跑、能用、能验证的原型，比先追求更炫的壳层更重要

## 5. 核心技术设计

### 5.1 分层结构

- UI 层：Tkinter 界面与交互状态
- 服务层：扫描、搜索、清理分析、清理执行
- 系统层：Windows Shell API、文件系统、资源管理器定位

### 5.2 扫描策略

- 使用 `os.scandir()` 做递归遍历
- 跳过符号链接，避免循环扫描
- 对权限不足和占用错误进行记录与跳过
- 自底向上聚合目录大小，得到最大目录列表

### 5.3 搜索策略

- 按关键词做大小写不敏感匹配
- 支持最小体积过滤
- 限制返回结果数量，避免 UI 过载
- 优先复用最近扫描产生的本地索引缓存，避免重复全盘遍历

### 5.4 清理策略

- 清理分析与清理执行分离
- 默认采用回收站而不是永久删除
- 对系统目录进行保护
- 对回收站清空直接调用 Windows Shell API

### 5.5 响应性策略

- 使用后台线程执行长任务
- 用事件队列将进度回传到主线程
- 保持界面在扫描和搜索时仍可更新状态

### 5.6 第二轮迭代优化

- 扫描完成后将文件索引快照持久化到本地缓存
- 重复扫描时优先复用新鲜缓存，必要时再强制重扫
- 搜索优先走索引缓存，索引过期时回退到实时遍历
- 通过“快照 + 强制刷新”平衡速度与同步正确性

## 6. 安全设计

- 受保护目录默认禁止删除
- 清理动作必须人工确认
- 清理失败项明确反馈
- 系统级动作不做暴力强删

## 7. 可维护性设计

- 服务逻辑集中在 `cclear/services.py`
- 界面逻辑集中在 `cclear/app.py`
- 通过单元测试验证关键扫描和清理逻辑
- 后续可在不改动核心服务层的前提下替换 UI 技术

## 8. 后续演进路线

### 8.1 短期

- 增加重复文件检测
- 增加更精细的风险分级
- 研究基于 Windows 文件变更通知的增量索引更新

### 8.2 中期

- 增加 Treemap 可视化
- 增加历史快照对比
- 增加定时清理策略

### 8.3 长期

- 如需更强性能与更现代 UI，可迁移到 Tauri 或原生 Windows 技术栈
- 保留 Python 版本作为稳定工具线或内部诊断版本

## 9. 结论

从“可运行、可验证、可快速迭代”的角度看，Python + Tkinter 是当前阶段最合理的技术选择。第二轮迭代已证明，这一路线不仅可以快速交付桌面原型，也能承载索引缓存、搜索复用与后续增量同步研究，非常适合 CClear 这一以本地磁盘治理为核心的桌面工具原型。
