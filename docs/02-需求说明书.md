# CClear 需求说明书

## 1. 项目背景

用户面临的核心问题是：C 盘空间长期紧张，但缺少一个简洁、可解释、可安全执行的桌面端工具，帮助快速定位空间占用来源，并完成低风险清理。

## 2. 目标用户

- 个人 Windows 用户
- 非专业运维用户
- 经常遇到 C 盘空间不足、系统更新失败、软件安装失败的用户

## 3. 核心目标

- 快速找出谁占用了 C 盘空间
- 支持按关键词和体积搜索大文件
- 给出可安全执行的清理建议
- 在清理前明确风险边界
- 用最少步骤完成空间回收

## 4. 非目标

- 不直接替代系统级分区工具
- 不做注册表清理
- 不做驱动级文件系统优化
- 不自动删除系统关键目录或 Windows 组件数据

## 5. 业务需求拆解

### 5.1 分析需求

- 支持对驱动器或目录进行扫描
- 输出总容量、文件数、目录数、占用体积
- 输出最大文件、最大目录、扩展名分布
- 对权限不足或被占用路径做跳过与提示

### 5.2 搜索需求

- 支持按关键词搜索文件
- 支持按最小大小过滤结果
- 搜索结果支持打开所在位置
- 搜索结果支持加入清理动作

### 5.3 清理需求

- 能识别临时文件清理机会
- 能识别用户可安全处理的大文件
- 默认清理方式为移动到回收站
- 高风险位置不能一键误删
- 对系统级清理动作必须单独确认

### 5.4 可解释性需求

- 明确告诉用户“为什么推荐清理这些内容”
- 明确告诉用户“哪些目录被保护或跳过”
- 清理结果要能看到已释放空间和失败项

## 6. 用户故事

- 作为普通用户，我希望一键扫描 C 盘，快速看到最大文件和目录，从而知道空间被谁占用了。
- 作为普通用户，我希望搜索“cache”“tmp”“log”等关键词，快速找到可疑文件。
- 作为谨慎用户，我希望删除动作默认进入回收站，而不是永久删除。
- 作为担心误删的用户，我希望系统目录被默认保护，并有风险提示。
- 作为空间紧张用户，我希望快速清理临时文件和回收站，立刻释放空间。

## 7. MVP 范围

### 7.1 必须具备

- 驱动器/目录选择
- 空间扫描
- 最大文件/目录展示
- 关键词搜索
- 临时文件分析
- 移动到回收站
- 清空回收站
- 风险提示与执行反馈

### 7.2 可以后续迭代

- Treemap 可视化
- 重复文件检测
- 扫描历史与对比
- 自动计划清理
- 存储趋势分析
- 白名单/黑名单规则

## 8. 功能性需求

### 8.1 扫描

- 输入：一个或多个目录根路径
- 输出：
  - 总大小
  - 文件数
  - 目录数
  - 最大文件列表
  - 最大目录列表
  - 扩展名分布
  - 跳过统计

### 8.2 搜索

- 输入：
  - 根路径
  - 关键词
  - 最小大小
- 输出：
  - 匹配路径
  - 文件大小
  - 修改时间
  - 所在目录

### 8.3 清理分析

- 输入：
  - 用户临时目录
  - Windows 临时目录
  - 文件保留天数阈值
- 输出：
  - 候选路径数
  - 估算可回收空间
  - 风险说明

### 8.4 清理执行

- 支持单个文件/目录移动到回收站
- 支持批量清理临时文件
- 支持清空回收站
- 对失败项返回错误信息

## 9. 非功能需求

### 9.1 安全性

- 默认不永久删除
- 默认保护系统关键目录
- 执行动作前必须确认

### 9.2 性能

- 能对常见个人电脑目录完成可接受的扫描
- 长任务期间可显示进度

### 9.3 易用性

- 首屏能直接开始扫描
- 信息分区清晰：扫描、搜索、清理
- 不要求用户理解复杂系统术语

### 9.4 可维护性

- 分析、清理、UI 分层
- 后续易扩展重复文件、可视化和计划任务

## 10. 风险边界

- `C:\Windows`、`C:\Program Files`、`C:\Program Files (x86)`、`C:\ProgramData` 等目录不能默认作为一键删除目标
- 对权限不足、正在使用、系统保护的内容只能提示，不能强删
- 对系统内建组件清理仍建议调用系统能力而不是自造破坏性逻辑

## 11. 验收标准

- 能运行桌面应用
- 能对指定目录扫描并输出统计结果
- 能搜索出匹配关键词的大文件
- 能分析出临时文件候选项
- 能把选中文件移动到回收站
- 能执行回收站清空
- 在异常场景下不崩溃，并提示失败原因
