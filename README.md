# CClear

CClear 是一个面向 Windows 的桌面端磁盘管理工具原型，重点解决 C 盘空间告急场景下的“看不清、找不快、删不准”问题。

## 当前原型能力

- 选择任意磁盘或目录进行空间扫描
- 扫描结果会建立本地索引缓存，短时间内可快速复用
- 查看总大小、文件数、目录数、最大文件、最大目录、扩展名分布
- 基于关键词和最小体积搜索大文件，并可优先走索引缓存
- 分析可安全清理的临时文件
- 将文件或目录移动到回收站
- 一键清理用户临时目录
- 调用 Windows 系统能力清空回收站

## 启动方式

```bash
python -m cclear
```

## 测试

```bash
python -m unittest discover -s tests -v
```

## 原型边界

- 当前版本基于 Python 标准库和 Tkinter 实现，不依赖第三方包
- 索引缓存用于加速重复扫描和搜索，默认采用快照复用而不是实时文件监控
- 默认采用移动到回收站而不是永久删除
- 复杂系统文件、组件存储、还原点等高级清理暂不自动处理
- 扫描超大磁盘时仍需要一定时间，当前版本已提供进度提示
